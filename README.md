# 서울 성형 가이드

서울에서 성형외과를 찾는 방문자를 위한 한국어 정적 사이트입니다. 견적 계산기, 상담 체크리스트, 공식 조회 안내를 포함합니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. 예시 이름은 `seoul-surgery-guide`입니다.
2. ZIP을 풀고 `index.html`이 저장소 최상위에 오도록 파일과 `assets` 폴더를 올립니다.
3. 저장소 → Settings → Pages → Source에서 Deploy from a branch를 선택합니다.
4. `main`과 `/(root)`를 선택하고 Save를 누릅니다. 배포 완료 후 Pages 설정에 표시된 공개 주소를 여세요.

[GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 배포 후 검색 등록

- 공개 주소가 확정되면 각 페이지에 실제 절대 주소로 canonical을 설정하고 같은 주소를 사용한 sitemap.xml을 작성하세요.
- 해당 주소를 Google Search Console과 네이버 서치어드바이저에 등록할 수 있습니다. 링크를 공유할 때는 비용 비교나 전문의 확인 등 관련 페이지 주소로 연결하세요.
- 초기 성과는 페이지별 노출, 검색 클릭, 사이트 유입으로 확인할 수 있습니다.

별도 설치 과정과 서버 코드 없이 동작합니다. 미리 보려면 index.html을 여세요.
